## Featured Projects

### Connect 4: Minimax vs. MCTS

A team project comparing two Connect Four AI agents built with Minimax, alpha-beta pruning, and Monte Carlo Tree Search. We ran 400 head-to-head games under different time constraints to compare their performance.

**Technologies and concepts:** Python, Minimax, MCTS

### Global Trends in Clean Cooking Fuels

A data-analysis project examining three decades of global data about access to clean cooking fuels. The project involved cleaning data, creating visualizations, and building linear regression models to study trends across countries.

**Technologies and concepts:** Python, data analysis, linear regression

### DungeonForge

A Dungeons & Dragons character-creation web application built as a team during HackNC 2023. I contributed to the HTML, CSS, and JavaScript used to build the application.

**Technologies:** HTML, CSS, JavaScript
